# 📊 Analisis Sentimen — Online Travel Agent & YouTube

Repository ini berisi **dua proyek analisis sentimen** yang menerapkan alur pemrosesan data yang serupa, tetapi menggunakan pendekatan yang berbeda pada tahap **pelabelan data** dan **preprocessing**.

### 📁 Isi Proyek

| Proyek                           | Sumber Data         | Fokus                                                |
| -------------------------------- | ------------------- | ---------------------------------------------------- |
| 🏨 **Online Travel Agent (OTA)** | Ulasan pengguna OTA | Analisis sentimen terhadap pengalaman pengguna pada 3 jenis aplikasi travel       |
| ▶️ **YouTube**                   | Komentar YouTube    | Analisis sentimen terhadap opini pengguna pada 3 jenis video |

Kedua proyek menggunakan alur utama yang sama:

```text
📥 Data Collection
       ↓
🧹 Data Cleaning
       ↓
🏷️ Sentiment Labeling
       ↓
🔤 Text Preprocessing
       ↓
📊 Exploratory Data Analysis
       ↓
🤖 Sentiment Analysis
       ↓
📈 Evaluation & Visualization
       ↓
    Inference
```

---

## 🎯 Tujuan Proyek

Kedua proyek ini dibuat untuk menerapkan proses **end-to-end sentiment analysis**, mulai dari data mentah hingga menghasilkan insight dan klasifikasi sentimen. saya menggunakan pelabelan yang berbeda untuk meilhat sejauh mana keakuratan pelabelan tersebut. didapatkan bahwa pelabelan lexicon tidak bisa memahami konteks.

Selain membandingkan hasil analisis, repository ini juga menunjukkan bahwa **karakteristik sumber data memengaruhi strategi pelabelan dan preprocessing** yang digunakan dalam pemrosesan teks.
